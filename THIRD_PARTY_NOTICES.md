# Données et visuels tiers

## Talents Forever

Les talents, livres de sorts et tooltips ont été adaptés à partir de [Talents Forever](https://talentsforever.com/), consulté le 3 novembre 2026. Les exports de données sont présentés par ce site sous licence [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/).

- https://talentsforever.com/export/priest.json
- https://talentsforever.com/export/paladin.json
- https://talentsforever.com/export/druid.json
- https://talentsforever.com/export/shaman.json

Adaptations : noms de sorts français lorsqu’ils ont été identifiés, descriptions françaises, sélection des outils de soin, regroupement par spécialisation et conseils pédagogiques. Le texte anglais de référence est conservé dans les fiches détaillées. Les chiffres ne sont pas des résultats de simulation et peuvent évoluer avec les correctifs.

Les listes d’armures et d’armes ont aussi été recoupées avec les tableaux de https://wowforevertalents.com/abilities/ ; les ambiguïtés sont signalées dans le guide.
